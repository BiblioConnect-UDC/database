# Base de Datos | Proyecto: BiblioConnect

Este repositorio oficial alberga **todo lo relacionado con la base de datos** del proyecto **BiblioConnect** - Sistema de Gestión Bibliotecaria.

Aquí encontrarás los elementos esenciales para la capa de datos del proyecto:

- **Diagramas Entidad-Relación (E-R)**: Representación visual del diseño de la base de datos.
- **Scripts SQL**:
    - Scripts para la **creación inicial** de tablas, índices y restricciones.
    - Scripts de **migración** de base de datos (si el proyecto utiliza migraciones para gestionar cambios en el esquema).
    - Scripts para **inicialización** de datos básicos (opcional, como roles de usuario predefinidos, etc.).
- **Documentación**: Información adicional sobre el diseño de la base de datos, decisiones clave y consideraciones de rendimiento.

Este repositorio está separado para **facilitar el desarrollo, versionado y la gestión** del esquema de la base de datos de forma clara y modular para todos los colaboradores del proyecto.
